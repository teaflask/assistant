# Security policy

## Reporting a vulnerability

Email <security@teaflask.com>. Do not open a public issue. The same
contact is published at <https://teaflask.com/.well-known/security.txt>
and <https://teaflask.com/security/>.

Include the package version, a reproduction, and the impact you see.

## Supported versions

The latest 0.x release only. A fix ships as the next 0.x version; earlier
versions are not patched.

## What to expect

You will hear back within a few business days that the report was
received, then updates while it is investigated. A confirmed
vulnerability is fixed in the next release, with an entry in
`CHANGELOG.md`, and you are credited there if you want to be.
