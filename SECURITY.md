# Security policy

## Reporting a vulnerability

Email <security@teaflask.com>. Please do not open a public issue. The same
contact is published at <https://teaflask.com/.well-known/security.txt>
and <https://teaflask.com/security/>.

Include the package version, steps to reproduce, and the impact you see.

## Supported versions

Only the latest 0.x release. A fix ships in the next release; earlier
versions are not patched, so upgrade to get it.

## What to expect

We will confirm that we received your report within a few business days,
then keep you updated while we investigate. A confirmed vulnerability is
fixed in the next release, and we publish a GitHub security advisory for
it on this repository. We are happy to credit you in the advisory if you
would like.
